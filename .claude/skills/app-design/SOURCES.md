# Sources

This skill is written fresh, but its practices draw on the most-used open-source design skills (stars as of November 2026) and on the platform guidelines. Read the originals for depth.

| Source | License | What this skill takes from it |
|---|---|---|
| [anthropics/skills, `frontend-design`](https://github.com/anthropics/skills) | see repo | plan the token system before code, review the plan against the brief, the list of AI-default tells, spend boldness in one place, writing as design content |
| [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | Apache-2.0 | PRODUCT.md + DESIGN.md pairing, surface modes (Persuade, Operate, Read, Experience), "shape" discovery before code, the craft floor, critique rubric, brief-wins rule |
| [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | MIT | priority-ordered rule categories, master design system + page overrides, W3C DTCG token export, variance/motion/density dials, pre-delivery checklist |
| [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | MIT | anti-generic discipline, real content and real imagery, verify in a real browser at fixed sizes |
| [Dammyjay93/interface-design](https://github.com/Dammyjay93/interface-design) | MIT | intent first (the human, the verb, the feel), domain exploration (domain, color world, signature, named defaults), hierarchy by weight and color, subtle layering, use-what-exists ladder, motion durations |
| [emilkowalski/skills](https://github.com/emilkowalski/skills) | MIT | Apple-style motion principles (springs, interruptibility, velocity handoff), native feel on mobile |
| [ehmo/platform-design-skills](https://github.com/ehmo/platform-design-skills) | MIT | per-platform rule structure and checklists (iOS, iPadOS, macOS, Android, web) |
| [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines) | MIT | web interaction, forms, focus and content handling rules |
| Apple Human Interface Guidelines, Material Design 3, Fluent 2 / Windows design, GNOME HIG, KDE HIG, WCAG 2.2 | n/a | platform conventions, metrics and accessibility requirements |

The owner's own `ipad-duo-design` skill defines the house style for Apple platforms and takes precedence there.
